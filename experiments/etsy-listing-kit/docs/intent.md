# Etsy Listing Kit — Founder intent

> "One design file, all the Etsy listing assets — built for embroidery sellers."
> — BHD Labs README, Etsy Patternator line

Embroidery and craft sellers finish a design and then face the *unpaid* second job:
producing every asset an Etsy listing needs — a clean hero image, correctly sized
gallery variants, and a framed mockup — before the listing can go live. That work is
tedious, repetitive, and stands between a finished design and a live, sellable listing.

This experiment tests the narrowest paid version of that job: **upload one design file →
pay once → download the complete pack of Etsy-ready listing assets.** No account, no
subscription, no workflow builder. One input, one transformation, one output, one price.

The business question is blunt: *will an embroidery seller pay a few dollars, right now,
to skip that asset-prep chore?* The revenue test ($100 of real Stripe payments in 14 days)
is the only thing that answers it.
